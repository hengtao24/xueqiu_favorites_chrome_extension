# 雪球收藏分组功能设计文档

**日期：** 2026-05-31  
**项目：** xueqiu-extension（Chrome MV3 扩展）  
**功能：** 为雪球收藏 Tab 添加自定义分组能力

---

## 1. 功能概述

在雪球用户收藏页（`xueqiu.com/u/:uid#/favorites`）注入自定义分组 UI，允许用户将收藏内容归类到自定义分组，并通过顶部 Tab 快速筛选浏览。

**核心特性：**
- 一条收藏可同时属于多个分组（标签模型，多对多）
- 分组数据本地存储，无需服务端
- 通过批量管理模式高效分配收藏

---

## 2. 整体架构

### 技术方案：XHR 拦截

在 content script 中拦截 `statuses/favorites.json` 的 XHR 响应，获取原始收藏数据后由扩展自行渲染列表和分组 UI。

**选择理由：** 雪球是 SPA，DOM 结构随时可能变更；XHR 拦截让扩展完全掌控数据，稳定性优于 DOM 监听方案。

### 模块结构

```
src/
  contentScript/
    index.js            入口，判断当前路径决定是否激活
    interceptor.js      XHR 拦截 + 内存数据缓存
    storage.js          chrome.storage.local 读写封装
    renderer.js         收藏列表渲染（含分组筛选逻辑）
    components/
      GroupTabBar.js    顶部分组 Tab 组件
      BulkManager.js    批量管理模式组件
      GroupEditor.js    分组新建/重命名/删除弹窗
    styles.css          注入样式
```

### 激活条件

仅在 URL 匹配 `xueqiu.com/u/*` 且 hash 为 `#/favorites` 时激活，其他页面不注入任何 UI。

---

## 3. 数据模型

数据存储于 `chrome.storage.local`，结构如下：

```js
{
  // 分组列表，有序
  "groups": [
    { "id": "g1", "name": "A股", "order": 0 },
    { "id": "g2", "name": "美股", "order": 1 },
    { "id": "g3", "name": "宏观", "order": 2 }
  ],
  // 收藏 → 分组映射（标签模型，一对多）
  "assignments": {
    "status_123": ["g1", "g2"],
    "status_456": ["g3"]
  }
}
```

**说明：**
- `id` 使用随机字符串，避免与 status id 冲突
- `order` 字段控制 Tab 显示顺序，支持拖拽排序
- 删除分组时，同步清除 `assignments` 中所有引用该 `id` 的记录
- 取消收藏时，`assignments` 中的孤立记录保留，不影响功能

---

## 4. 数据流

```
用户访问收藏页
  → index.js 检测路径，激活扩展
  → interceptor.js 拦截 statuses/favorites.json 响应
  → 原始数据存入内存缓存（支持分页合并）
  → renderer.js 从 storage 读取分组配置
  → 按当前选中 Tab 筛选数据，渲染列表

用户切换 Tab
  → GroupTabBar 触发事件
  → renderer.js 重新筛选渲染（无需重新请求网络）

用户批量操作
  → BulkManager 收集选中的 status id 和目标分组
  → storage.js 写入 assignments
  → renderer.js 刷新列表（更新分组标签显示）

无限滚动加载
  → 新页请求被拦截，数据合并入缓存
  → renderer.js 增量追加新卡片
```

## 5. UI 组件规范

### 5.1 GroupTabBar（顶部分组标签栏）

注入位置：收藏列表容器顶部。

**布局：**
- 左侧：「全部」Tab + 各自定义分组 Tab（横向排列）
- 右侧：「✏️ 批量管理」按钮 + 「+ 新建分组」按钮
- 每条收藏卡片底部显示其所属分组标签（蓝色文字）

**交互：**
- 点击 Tab → 切换当前分组视图
- 右键 Tab → 弹出「重命名」「删除」菜单
- 点击「+ 新建分组」→ 打开 GroupEditor 弹窗

### 5.2 BulkManager（批量管理模式）

点击「批量管理」后激活，点击「退出」或按 Esc 退出。

**激活后：**
- 列表顶部出现操作栏：「已选 N 条」+ 分组下拉选择 + 「确定」+ 「退出」
- 每条收藏左侧出现复选框
- 点击复选框选中/取消，操作栏计数实时更新
- 「确定」→ 将选中收藏添加到指定分组（不覆盖已有分组）

### 5.3 GroupEditor（分组管理弹窗）

**功能：**
- 显示现有分组列表，支持拖拽调整顺序
- 每项可「重命名」（行内编辑）或「删除」（需确认）
- 底部输入框新建分组，回车或点击「添加」确认

## 6. 色彩规范

| 用途 | 颜色值 |
|------|--------|
| 主色（选中 Tab 文字/下划线、按钮边框、分组标签）| `#1B7BF5` |
| 选中 Tab 背景 | `#E8F1FE` |
| 未选中 Tab 文字 | `#666666` |
| 危险操作（删除）| `#FF3B30` |

扩展注入的所有 CSS 类名以 `xq-ext-` 为前缀，避免与雪球原生样式冲突。

---

## 7. 边界情况

| 情况 | 处理方式 |
|------|----------|
| 收藏数为 0 | 显示「暂无收藏」占位，分组 Tab 仍可管理 |
| 分组内收藏数为 0 | Tab 正常显示，内容区显示「该分组暂无收藏」 |
| 分组名重复 | 前端校验，提示用户修改 |
| 存储达到上限（5MB）| 提示用户清理旧分组数据 |
| 雪球页面结构变更导致注入点失效 | 降级：不注入 UI，不影响雪球原有功能 |

---

## 8. 不在范围内

- 跨设备同步（当前用 `chrome.storage.local`，未来可升级为 `sync`）
- 分组内收藏的手动排序
- 自动规则分组（按股票代码、关键词等）
- 对他人收藏页的支持
